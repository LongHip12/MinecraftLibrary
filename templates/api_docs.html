AI Chat API

REST API for Lonely Hub AI Chat — 7 models, session-based or token-based access.

Unified API
Single endpoint — all 7 models
Send messages to any model through one endpoint. Authenticate with your personal API token (no session cookie needed). Works exactly like calling NVIDIA NIM or OpenRouter — just swap the base URL and use your Lonely Hub token.
POST /api/v2/chat/ai

Request

Header / FieldTypeRequiredDescription

modelstringOptionalModel key — see list below. Default: gpt-4o-mini
messagesarrayRequiredOpenAI-style array: [{"role":"user","content":"..."}]
thinkingbooleanOptionalEnable reasoning output (models with reasoning support only)
streambooleanOptionalStream via Server-Sent Events

Response

FieldTypeDescription
successbooleanWhether the request succeeded
outputstringAI response text (Markdown)
thinkingstring|nullReasoning block (if enabled and supported)
modelstringModel key used

errorError message

Basic request
python
import requests

resp = requests.post(
    "https://lonelyhub.net/api/v2/chat/ai",
    headers={"X-Token": "YOUR_API_TOKEN", "Content-Type": "application/json"},
    json={
        "model": "gpt-4o-mini",
        "messages": [{"role": "user", "content": "How do I make a Minecraft mod?"}],
    },
)
data = resp.json()

Multi-turn conversation
python
import requests

URL = "https://lonelyhub.net/api/v2/chat/ai"
HEADERS = {"X-Token": "YOUR_API_TOKEN", "Content-Type": "application/json"}
history = []

def chat(msg, model="gpt-4o-mini"):
    history.append({"role": "user", "content": msg})
    r = requests.post(URL, headers=HEADERS, json={"model": model, "messages": history})
    reply = r.json()["output"]
    history.append({"role": "assistant", "content": reply})
    return reply

print(chat("What is the best Minecraft modding framework?"))
print(chat("Can you show me an example mod?"))
Reasoning model
python
import requests

r = requests.post(
    "https://lonelyhub.net/api/v2/chat/ai",
    headers={"X-Token": "YOUR_API_TOKEN", "Content-Type": "application/json"},
    json={
        "model": "nvidia-nemotron",
        "messages": [{"role": "user", "content": "Explain Minecraft chunk loading"}],
        "thinking": True,
    },
)
d = r.json()
if d.get("thinking"):
    print(f"[Reasoned]\n{d['thinking']}\n---")
print(d["output"])
Streaming response
python
import requests, json

r = requests.post(
    "https://lonelyhub.net/api/v2/chat/ai",
    headers={"X-Token": "YOUR_API_TOKEN", "Content-Type": "application/json"},
    json={
        "model": "gpt-4o-mini",
        "messages": [{"role": "user", "content": "Tell me about redstone"}],
        "stream": True,
    },
    stream=True,
)
for line in r.iter_lines():
    if not line: continue
    text = line.decode() if isinstance(line, bytes) else line
    if text == "data: [DONE]": break
    if text.startswith("data: "):
        ev = json.loads(text[6:])
        if ev["type"] == "content":
            print(ev["content"], end="", flush=True)
print()
Session-based endpoints (requires login cookie)
POST /api/ai/send Send message, get AI reply

Requires an active login session. Stores the message in chat history and returns the AI reply. Creates a new chat if no chat_id is provided.

Request body

FieldTypeRequiredDescription
modelstringOptionalModel key. Default: gpt-4o-mini
messagestringRequiredUser message text
chat_idstringOptionalContinue an existing chat. Omit to start new.
thinkingbooleanOptionalEnable reasoning (reasoning models only)
filesarrayOptionalFile objects: {"name","type","data"(base64),"text_content"}

Response

FieldTypeDescription
successbooleanRequest status
chat_idstringChat UUID — reuse for follow-up messages
titlestringAuto-generated chat title
outputstringAI response (Markdown)
thinkingstring|nullReasoning block
thinking_timeintegerSeconds spent reasoning
model_namestringDisplay name of model used
model_imagestringModel avatar URL

Python example

python
import requests

session = requests.Session()
# Copy your session cookie from browser DevTools
session.cookies.set("session", "YOUR_SESSION_COOKIE", domain="lonelyhub.net")

resp = session.post("https://lonelyhub.net/api/ai/send", json={
    "model": "gpt-4o-mini",
    "message": "How do I create a Minecraft mod in Java?",
})
data = resp.json()
chat_id = data["chat_id"]
print(data["output"])

# Continue the chat
resp2 = session.post("https://lonelyhub.net/api/ai/send", json={
    "model": "gpt-4o-mini",
    "message": "Can you show a full example?",
    "chat_id": chat_id,
})
print(resp2.json()["output"])

GET /api/ai/chats List all chats

Returns a summary list of all chats for the logged-in user (no messages, just metadata).

Response

FieldTypeDescription
successbooleanRequest status
chatsarrayList of chat objects: id, title, pinned, updated_at, model

Python example

python
resp = session.get("https://lonelyhub.net/api/ai/chats")
for chat in resp.json()["chats"]:
    print(chat["id"], chat["title"])
GET /api/ai/chats/{chat_id} Get full chat with messages

Returns the full chat object including all messages.

Response

FieldTypeDescription
successbooleanRequest status
chatobjectFull chat: id, title, model, pinned, messages[]

Python example

python
resp = session.get(f"https://lonelyhub.net/api/ai/chats/{chat_id}")
chat = resp.json()["chat"]
for msg in chat["messages"]:
    print(f"[{msg['role']}]", msg["content"][:80])
PATCH /api/ai/chats/{chat_id} Rename or pin a chat

Request body

FieldTypeRequiredDescription
titlestringOptionalNew chat title
pinnedbooleanOptionalPin or unpin the chat

Python example

python
# Rename
session.patch(f"https://lonelyhub.net/api/ai/chats/{chat_id}",
    json={"title": "My new chat name"})

# Pin
session.patch(f"https://lonelyhub.net/api/ai/chats/{chat_id}",
    json={"pinned": True})
DELETE /api/ai/chats/{chat_id} Delete a chat

Permanently deletes the chat and all its messages.

Python example

python
resp = session.delete(f"https://lonelyhub.net/api/ai/chats/{chat_id}")
print(resp.json())  # {"success": true}
GET /api/ai/models List available models

Returns the full model configuration object (public, no auth required).

Python example

python
import requests
models = requests.get("https://lonelyhub.net/api/ai/models").json()["models"]
for key, cfg in models.items():
    print(key, "—", cfg["name"], "reasoning:" if cfg["thinking"] else "")
