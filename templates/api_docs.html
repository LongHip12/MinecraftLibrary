AI Chat API

REST API for the Lonely Hub AI Chat — send messages to any of the 7 supported models.

Endpoint

POST/api/ai/send

Requires authentication. The user must be logged in (session cookie). Returns the AI response, chat ID, and optional reasoning block.

Request Body

FieldTypeRequiredDescription
modelstringRequiredModel ID (see list below). Defaults to gpt-4o-mini.
messagestringRequiredThe user's message text.
chat_idstringOptionalContinue an existing chat. Omit to start a new one.
thinkingbooleanOptionalEnable reasoning/thinking mode (only for models that support it).
filesarrayOptionalArray of file objects: {name, type, data (base64), text_content}.

Response

FieldTypeDescription
successbooleanWhether the request succeeded.
outputstringThe AI's response text (Markdown).
chat_idstringThe chat session UUID (use for follow-up messages).
titlestringAuto-generated chat title.
thinkingstring|nullReasoning block text (if thinking was enabled).
thinking_timeintegerSeconds spent reasoning.
model_namestringDisplay name of the model used.

Python Examples

Start a new chat

python
import requests

  session = requests.Session()
  # You must be logged in — copy your session cookie from the browser
  session.cookies.set("session", "YOUR_SESSION_COOKIE", domain="lonelyhub.net")

  resp = session.post("https://lonelyhub.net/api/ai/send", json={
      "model": "gpt-4o-mini",
      "message": "How do I create a Minecraft mod in Java?"
  })
  data = resp.json()
  print(data["output"])
  print("Chat ID:", data["chat_id"])

Continue a chat

python
resp = session.post("https://lonelyhub.net/api/ai/send", json={
      "model": "gpt-4o-mini",
      "message": "Can you show me a full example?",
      "chat_id": data["chat_id"]   # reuse the ID from the first response
  })
  print(resp.json()["output"])

Use a reasoning model

python
resp = session.post("https://lonelyhub.net/api/ai/send", json={
      "model": "nvidia-nemotron",
      "message": "Explain how Minecraft chunk loading works",
      "thinking": True    # enable reasoning/thinking mode
  })
  result = resp.json()
  if result.get("thinking"):
      print(f"[Reasoned for {result['thinking_time']}s]")
      print(result["thinking"])
      print("---")
  print(result["output"])

List all chats

python
resp = session.get("https://lonelyhub.net/api/ai/chats")
  for chat in resp.json()["chats"]:
      print(chat["id"], chat["title"])

Delete a chat

python
resp = session.delete(f"https://lonelyhub.net/api/ai/chats/{chat_id}")
  print(resp.json())  # {"success": true}
